# 零基础上手：让 AI 帮你配置

这一模块不是教你先学会工具，而是给你**可以直接复制给 AI 的提示词**，让 AI 自己检查环境、安装工具、写配置、验证连接。

::: warning 先分清：普通聊天 AI 和能操作电脑的 AI
普通网页版 ChatGPT、Claude 等通常只能给建议，不能替你执行本机命令、安装软件或修改配置。下面这套流程需要能操作你电脑的桌面端或 Agent。
:::

## 第一步：打开一个能操作你电脑的 AI

推荐按这个顺序选择：

1. **已经有 Codex**：直接打开 Codex。
2. **还没有 Codex**：先安装并打开 **ChatGPT 桌面端**，登录你的账号。
3. **使用其他工具**：打开 Claude Code、OpenCode 或其他明确支持“运行命令 / 操作电脑”的 Agent。

打开后照做：

1. 新建一个对话。
2. 复制下面[“最省事的起点”](#最省事的起点)中的整段提示词。
3. 粘贴并发送。
4. 它提问时如实回答；不确定就回答“我不知道，请先帮我检查”。
5. 涉及 API Key 时，按 AI 给出的安全路径自己填入，不要把完整密钥粘贴到聊天里。

::: tip Windows 用户先看
如果你使用 Windows，先阅读 [Windows 必读](./windows)，了解 PowerShell、CMD 和路径写法的区别，再开始下面的步骤。
:::

## 我现在有什么？下一步做什么？

| 你的情况 | 下一步 | 去哪里 |
| --- | --- | --- |
| 没有任何账号，也没有 API Key | 先选择免费或试用模型，按页面指引注册并取得 Key | [免费与试用模型](./free-models) |
| 有账号，但还没创建 API Key | 登录服务商控制台，创建并保存 API Key | [创建并保存 API Key](/guide/api-key) |
| 有 API Key，但还没安装工具 | 让能操作电脑的 AI 检查环境、安装工具并写入配置 | [让 AI 安装并配置工具](./first-run) |
| 有 Key、想自己动手跑通一遍 | 按固定示例从查模型一路走到验证 tool call | [15 分钟最小接入](./quickstart) |
| 工具装好了，但用不了或报错 | 先按失败分类找到该问谁，并复制脱敏后的报错 | [配置失败怎么办](./help) |

::: tip 不确定自己属于哪一种？
把你知道的信息（操作系统、服务商名称、是否已有 Key、报错原文）直接发给能操作电脑的 AI，让它先判断，再带你去对应页面。
:::

## 最省事的起点

如果你不知道选哪个工具，先把下面提示词里的 `<Windows/macOS/Linux>` 换成你的系统，例如 `Windows 11`；如果不确定，就写“我不知道，请先帮我检查”。然后把整段发给 AI：

```text
我想在一台 <Windows/macOS/Linux> 电脑上使用 AI 编程工具，但我完全不懂命令行。
请先检查我的系统环境，然后推荐一个最容易安装的工具（优先 OpenCode）。
请你直接帮我完成安装和配置，每一步都告诉我你在做什么。
涉及 API Key 时，让我自己粘贴，不要让我把完整密钥发给你。
配置完成后，请实际运行验证命令，并把结果告诉我。
```

## 这个模块解决什么

- 不知道装什么工具
- 不会命令行
- 不会找配置文件
- 不会配 Base URL 和 Key
- 配完不知道有没有成功
- 出错后不知道怎么让 AI 排查
