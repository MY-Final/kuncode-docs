# 零基础上手：让 AI 帮你配置

这一模块不是教你先学会工具，而是给你**可以直接复制给 AI 的提示词**，让 AI 自己检查环境、安装工具、写配置、验证连接。

你只需要：

1. 打开一个能帮你操作电脑的 AI（Codex、Claude Code、ChatGPT 桌面端等）。
2. 把本页的提示词复制给它。
3. 它问你什么，你回答什么。
4. 涉及 API Key 时，按它给的路径自己填入，不要把完整密钥贴在聊天里。

## 最省事的起点

如果你不知道选哪个工具，直接把这段发给 AI：

```text
我想在一台 <Windows/macOS/Linux> 电脑上使用 AI 编程工具，但我完全不懂命令行。
请先检查我的系统环境，然后推荐一个最容易安装的工具（优先 OpenCode）。
请你直接帮我完成安装和配置，每一步都告诉我你在做什么。
涉及 API Key 时，让我自己粘贴，不要让我把完整密钥发给你。
配置完成后，请实际运行验证命令，并把结果告诉我。
```

## 这个模块解决什么

- 不知道装什么工具
- 不会命令行
- 不会找配置文件
- 不会配 Base URL 和 Key
- 配完不知道有没有成功
- 出错后不知道怎么让 AI 排查
