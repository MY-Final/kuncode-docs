# 免费与试用模型

::: warning 免费政策变化很快
本文只讲"怎么让 AI 帮你找和判断"，不承诺任何服务长期免费。额度、可用模型、速率限制、是否需要绑卡，一律以服务商官方页面为准。最后整理时间：2026-10。
:::

## 直接让 AI 帮你选

把下面这段发给 AI：

```text
我想先用免费额度体验 AI 编程工具，不想马上付费。
请先确认我所在地区可能可用的免费方案，比较它们的额度、模型、是否支持 tool call、是否有速率限制。
优先推荐配置最简单的方案。
不要推荐来路不明的共享 Key 或第三方中转站。
确认方案后，请直接帮我配置到本机，并实际验证能否调用。
```

## 免费路径的大致分类

### 1. 工具自带免费模型

有些工具自带免费模型或免费额度，装完就能用，不需要自己配 Base URL。

让 AI 检查当前工具是否有免费入口，例如在 OpenCode 里查看 `/models`。

优点：配置最少。缺点：模型和时间有限制。

### 2. 云服务免费额度

很多平台给新用户免费额度，或提供长期免费模型。常见入口包括：

| 平台 | 常见免费形式 | 要注意 |
| --- | --- | --- |
| Google AI Studio / Gemini | 免费层 + 每日额度 | 可能有地区和速率限制 |
| Groq | 免费层，速度较快 | 模型选择有限 |
| OpenRouter | 部分模型标 `:free` | 限速明显，可能排队 |
| GitHub Models | 面向开发者的试用额度 | 需要 GitHub 账号 |

让 AI 帮你核对当前政策，不要凭旧教程直接注册。

### 3. 本地模型

在自己电脑上跑，不消耗 API 额度。

- **Ollama**：命令行安装，拉模型即可。
- **LM Studio**：图形界面，适合不熟悉命令行的用户。

代价是需要一定的内存或显存，速度取决于硬件。

## 让 AI 判断"免费"能不能用

把这段发给 AI：

```text
请检查我准备使用的免费方案，逐项回答：
1. 是否需要绑银行卡
2. 额度是每天重置还是一次性
3. 支持哪些模型
4. 是否支持 tool call
5. 支持哪个协议入口
6. 有没有速率或并发限制
7. 数据是否会被用于训练

如果其中任何一项会导致 AI 编程工具无法正常使用，请直接告诉我，并换一个方案。
```

## 安全提醒

- 不要用来路不明的免费 Key、共享 Key 或"中转站"。
- 不要把 Key 提交到 Git、发到群里或截图露出。
- 免费额度被限速、被回收都很常见，重要工作请用付费服务。
