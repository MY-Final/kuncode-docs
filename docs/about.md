# 关于本文档

## 这是一份通用文档

这里整理的是 AI 编程工具接入模型的通用方法，包括 Codex、Claude Code、OpenCode、GitHub Copilot CLI 等。

它面向所有人开放：

- **不要求使用 KunCode**，你完全可以照着接入自建网关、第三方服务或官方 API
- 页面里的地址、密钥、模型名都是可替换的占位值
- 协议说明、配置格式、排障思路与具体服务商无关

## 为什么会有 KunCode 示例

为了让示例可以直接跑通，文档中大部分演示使用 KunCode 作为参考地址。

这只是一个例子。你把它换成任何兼容服务的地址，配置同样成立。

## 开源与共享

我们相信接入文档不应该被绑定在某一个平台上。

只要这份文档能帮你少踩一个坑，用不用 KunCode 都没关系。欢迎参考、转载和改写。
