::: info About this guide
This is a **provider-agnostic setup guide**. Its protocol notes, configuration patterns and troubleshooting advice apply to official APIs, self-hosted compatible gateways and third-party compatible services.

KunCode appears only as an optional example. It is neither required nor the only supported service. This site does not provide account signup, key issuance, top-ups or provider support; those are handled by your service provider's documentation and console.
:::
