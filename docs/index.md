::: info 文档定位
这是一份 **provider-agnostic 接入指南**：协议、配置和排障思路适用于官方 API、自建兼容网关和第三方兼容服务。

KunCode 仅作为可选示例，不是前置条件，也不代表唯一支持的服务。本站不提供开户、发放 Key、充值或平台客服；这些事项以你的服务商文档和控制台为准。
:::
