# 准备 API Key

AI 编程工具需要通过密钥调用模型接口。密钥可以来自任何你信任的服务商，包括自建网关。

## 获取密钥

不同服务的获取方式不同，通常在控制台的「令牌」「API Keys」或「密钥」页面：

1. 创建一个新密钥，填写名称。
2. 按需设置额度上限、过期时间、可用模型或分组。
3. 保存后复制密钥，形如 `sk-xxxxxxxx`。

::: warning 密钥只显示一次
多数服务在创建后不再回显完整密钥，请立即保存到密码管理器。若丢失，删除后重新创建。
:::

## 权限建议

| 场景 | 建议 |
| --- | --- |
| 个人本地开发 | 单独创建一个密钥，设置较低额度上限 |
| 团队共用 | 按成员或项目分别创建，便于对账 |
| CI / 自动化 | 使用独立密钥，并限制模型与分组 |

## 验证密钥是否可用

把地址和密钥替换成你自己的：

```bash
curl https://your-gateway.example.com/v1/models \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

返回模型列表即表示密钥可用。若返回 `401`，见 [常见问题](/faq)。
